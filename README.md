## 🌟 Key Features

### 1. 📊 Executive Overview & Real-Time KPIs
- **Today's Energy Usage (kWh)**: Instant readout of current-day consumption and cost.
- **Current Month Accumulated Units**: Total units consumed in the active billing cycle.
- **Progressive Slab Bill Estimate**: Live cost calculation based on real utility tariff rules.
- **30-Day Forward ML Forecast**: Predictive forecast generated by the machine learning regression engine.

### 2. 📝 Smart Cumulative Meter Reading Entry
- **Automatic Previous Reading Pre-fill**: Dynamically fetches the user's latest recorded cumulative meter reading (`suggested_prev_reading`), removing manual guesswork.
- **Real-Time Live Delta Calculation**: Instantly computes $Current − Previous = \text{Consumed kWh}$ as you type.
- **Sanity Checks & Validation**: Prevents negative values, inverted readings, or non-chronological anomalies.

### 3. ₹ Progressive Multi-Tier Tariff Slab Engine
- Modeled after real-world utility billing structures (e.g., State Electricity Boards & TNEB):
  - **Slab 1 (0 – 100 units)**: 100% Subsidized / Free (₹0.00 / unit)
  - **Slab 2 (101 – 200 units)**: ₹2.25 / unit
  - **Slab 3 (201 – 400 units)**: ₹4.50 / unit
  - **Slab 4 (401 – 500 units)**: ₹6.00 / unit
  - **Slab 5 (> 500 units)**: ₹8.00 / unit
- Incorporates mandatory **Fixed Meter Demand Charges** (₹50.00) and **Electricity Duty / Tax** (5%).
- Visual tier-progress meters indicating exact capacity usage across each slab.

### 4. 🤖 Scikit-Learn Machine Learning Bill Forecasting
- **Algorithm**: Ordinary Least Squares (OLS) `LinearRegression()` trained on historical chronological consumption.
- **Statistical Goodness-of-Fit**: Calculates Coefficient of Determination ($R^2$) score in real time.
- **Mathematical Model Formulation**: Visualizes the daily trend line ($y = mx + c$) and slope trajectory.
- **30-Day Forward Forecast**: Projects upcoming month's kWh demand and passes it to the multi-slab engine for predicted bill calculation.

### 5. 📈 Consumption Analytics & Interactive Simulator
- **Daily Consumption History Chart**: Chart.js visual tracking of daily kWh trends with smooth curve interpolation.
- **Month-over-Month Comparative Analytics**: Dual-axis bar chart comparing energy consumption vs. expenditure with percentage variance analysis.
- **"What-If" Electricity Bill Calculator**: Interactive range slider (10 to 800 kWh) for real-time bill previews and slab-tier discovery.

### 6. 🕒 Meter Readings Audit History & CSV Export
- Fully searchable, chronological audit table of all saved meter entries.
- One-click **CSV export** for spreadsheet analysis and personal records.
- Individual entry deletion with cascade database safety.

### 7. 📄 Certified PDF Energy Audit Report
- Generates official PDF energy audit reports on-demand using the **ReportLab** document engine.
- Includes consumer account details, tariff breakdown tables, usage trends, and recent reading logs.

### 8. 🔐 Authentication & Quick Access
- **Local Authentication**: Secure password hashing (`Werkzeug PBKDF2:SHA256`).
- **Interactive 1-Click Demo Login**: Explore all features instantly without typing credentials.
- **Google OAuth 2.0 Integration**: Sign in with Google Identity Services.

## 🚀 Getting Started (Local Development)

### 1. Clone the Repository
```bash
git clone https://github.com/priyadharshini-cloud/EnergyConsumptionSystem.git
cd EnergyConsumptionSystem
```

### 2. Set Up a Virtual Environment
```bash
# Windows
python -m venv .venv
.\.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python backend/app.py
```

### 5. Access the Web Application
Open your browser and navigate to:
```
https://energyconsumptionsystem.onrender.com  
```
- Click **Quick Demo Login →** to enter the live dashboard immediately.
- Use **⚡ Load 60-Day Sample Data** in the sidebar to populate realistic demonstration records.
